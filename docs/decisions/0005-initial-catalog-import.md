# Первоначальный каталог, комплекты и изображения

Дата: 2026-10-28. Реализовано по поручению пользователя и уточнениям данных.

## Владение и загрузка

`catalog-audit` читает XLSX без исполнения формул и сохраняет все листы,
координаты ячеек, значения и формулы отдельно. `catalog-import` — отдельный
ограниченный процесс каталога, а не обработчик HTTP. Перед публикацией строит
и проверяет весь набор. Использует только каталоговый LOGIN, одно соединение,
лимиты SQL/ожидания блокировок и общий deadline. Данные каталога, исходные строки
и связи с фото публикуются одной транзакцией.

Исходные книги хранятся в `catalog.import_batches`, строки — в `catalog.source_rows`.
Хеш входных книг и версии нормализации идентифицирует первоначальную загрузку.
Повтор уже опубликованного набора — no-op: не меняет ручные правки и остатки.
Новый набор с существующим SKU отклоняется целиком; это не регулярная
синхронизация поставщика. Для неё потребуется отдельный согласованный протокол
проверки и публикации изменений. Действующие заявки не переписываются.

## Словарь

| Excel | Поле БД / смысл |
|---|---|
| Артикул | sku, уникальный непустой код; UUID стабильно выводится из SKU |
| Название, Цена | name, unit_price_rub — целые рубли за единицу продажи |
| Количество шин | stock — текущий запас в штуках, подтверждено пользователем |
| Остаток шин | tread_percent — процент протектора, не запас |
| Бренд, Модель, Год выпуска | brand, model, production_year |
| Размер, Сезонность | size (исходная строка), season |
| Нагрузка, Скоростной индекс | load_index (включая PR), speed_index |
| Место, Описание | location (только админка), description |
| Количество дисков в комплекте | units_per_sale |
| Количество комплектов | stock — число продаваемых единиц/комплектов |
| Состояние, Тип диска | condition, wheel_type |
| Диаметр, Ширина | diameter, width — дюймы |
| Вылет, Сверловка, Диаметр ЦО | wheel_offset, pcd, center_bore — размеры в мм |
| Фото | упорядоченные строки catalog.product_images; исходный список в source_rows |

Неизвестные числовые характеристики — NULL, не ноль. Типоразмер шины
не раскладывается в выдуманные метрические размеры; геометрия диска хранится
в numeric. Пробелы по краям удаляются, символы x/х/* в PCD нормализуются;
исходный вид остаётся в сохранённых ячейках. Сводки сохраняются, но их
ошибочные формулы не используются для расчёта складского запаса.

## Единица продажи

Пользователь подтвердил продажу позиции из двух дисков только комплектом.
Для неё stock=1, units_per_sale=2, цена 25 000 рублей за комплект.
Оформление количества 1 означает один комплект; передача в доставку списывает
одну единицу stock. Это уточнение первоначального правила «всегда за штуку».
`unit_label` сохраняется в снимке позиции заявки и истории; старые позиции
получают «шт.». Единицу уже созданного товара нельзя сменить через админку:
это изменило бы смысл незавершённых заявок. Для новой комплектации нужен новый товар.

## Фотографии

Производные: WebP 1280×1280, quality 85, полный кадр, без увеличения исходника,
белые поля, поворот по EXIF, sRGB. EXIF/ICC/XMP/IPTC удаляются. Визуально
проверен пилот шины и комплекта дисков; все выходы проверены по размерам,
формату и отсутствию метаданных. Оригиналы неизменны.

Путь `/media/products/<uuid>/<sha256>-1280-v1.webp`. Таблица хранит порядок,
путь оригинала, checksum и размеры; первый снимок — обложка. Список Excel
задаёт порядок, дополнительные фото своего артикула из его папки добавляются
в конец. Только явно подтверждённые ошибки сопоставления исправляются.
Чужой артикул не привязывается автоматически. Дубликаты содержимого внутри
товара не повторяются. Непривязанные фото конвертируются в приватную `.tmp`.

Производные размещаются в игнорируемом `frontend/public/media`, Vite переносит
их в статическую сборку. В Git только код и синтетические тесты. При отсутствии
изображений или ошибке загрузки используется существующий рисунок.
Публичный hosting и внешняя публикация в эту задачу не входят.

## Неопределённые данные

По решению пользователя столбцы процентов имеют приоритет над названиями;
вылет одного диска подтверждён отдельно. Исправления помечены review_notes.
Семь противоречий «новая/б/у» требуют отдельной проверки: данные сохранены,
товары скрыты, замечания доступны в админке. Полный локальный отчёт —
`.tmp/catalog-import/RESULT.md`; исходные значения не заменены исправленными.
