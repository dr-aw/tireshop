# SSG публичной витрины

Принято 2026-11-09. React/Vite сохраняются. Render получает готовые HTML,
React гидратирует их; цена и наличие перепроверяются API. SSR runtime не нужен.
Информационные страницы используют отдельный лёгкий entry point, админка — свой.

Каталог владеет `GET /api/products/snapshot`: один SQL statement даёт согласованный
снимок всех доступных публичных товаров, включая нулевой остаток. `is_available=false`
означает скрытие из публикации, как в текущем списке API; отдельного признака
архивной публичной карточки пока нет. Внутренние location/review_notes очищаются.
Лимит 10000 товаров, один одновременный экспорт на экземпляр, timeout 10 секунд.
Ответ: schema_version=1, version (SHA-256 items), generated_at UTC, items.
Снимок без товаров допустим для API, но публикация требует явного разрешения
пустого каталога. Клиент сборки ограничивает ответ 32 MiB и время 20 сек.

Корень остаётся каталогом. Категории `/catalog/tires/`, `/catalog/wheels/`,
пагинация `/catalog/[category/]page/N/`, карточки `/products/{uuid}` без смены ID.
Информационные страницы имеют trailing slash. Фильтры остаются query UI, noindex
после запуска клиента; canonical указывает базовую категорию. Пагинация имеет
собственный canonical. Не блокируем JS/API robots.txt. Корзина `/cart/` noindex;
старые inline checkout остаются совместимыми в первой версии.

HTML и initial data формируются одним React-деревом. Browser storage читается
после гидратации, а не при первом render. Чужой текст экранируется React;
JSON в script экранирует `<`. Сборка использует файл снимка или явный API URL;
по умолчанию только синтетические данные dev. Render требует API URL и origin.
Перед публикацией snapshot повторно проверяется: изменение версии отменяет сборку.

Новый dist готовится отдельно; при ошибке предыдущий артефакт не удаляется.
Публикация сначала ручная, расписание не включается до проверки HTTP 404,
закреплённого commit и успешной публикации. Deploy hook без закрепления версии
кода не подходит. Render custom 404 требует отдельной внешней проверки; нельзя
заменять HTTP 404 rewrite-ответом 200. Инструкции — в руководстве публикации.
