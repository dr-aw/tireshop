# Источники SVG мессенджеров

- WhatsApp и Telegram: [Font Awesome Free Brands](https://github.com/FortAwesome/Font-Awesome/tree/7.x/svgs/brands),
  Fonticons, Inc., лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Исходные license comments сохранены; fill заменён на зелёный/голубой.
- MAX: [официальный favicon MAX](https://max.ru/favicon.svg). Извлечён контур
  знака из маски, градиент заменён на фиолетовый fill. Знак принадлежит MAX;
  лицензия Font Awesome к нему не относится.

SVG находятся в frontend/public/branding/messengers; загрузки со сторонних
сайтов во время открытия страницы нет. Названия и знаки используются для
идентификации способов связи, без заявления о партнёрстве.
