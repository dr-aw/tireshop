# Подбор товаров

`GET /api/products` и защищённый `GET /api/admin/products` используют один
валидатор и построитель запроса. Значения передаются SQL-параметрами;
имена полей и направление сортировки выбираются из разрешённого списка.
Публичный список всегда содержит только `is_available=true`, независимо
от фильтров. Публичный GET по ID сохраняет прежнее поведение.

Ответ списка: `{items: [...], total: 123}`. `total` — число совпадений до
пагинации, включая случай пустой страницы. Цена и запас имеют единицу продажи
товара (штука или комплект); цена не пересчитывается в стоимость одного диска.
Список и количество читаются отдельно: при параллельном изменении каталога
количество может кратковременно отличаться от страницы.

## Параметры

- `limit`: 1–100, по умолчанию 24 для витрины и 50 для админки.
- `offset`: 0–100000, по умолчанию 0.
- `kind`: `tyre` или `wheel`; пусто — все категории.
- `q`: до 200 символов, поиск подстроки без учёта регистра по названию,
  артикулу и размеру. `%`, `_`, обратная косая черта — обычные символы.
- Общие точные фильтры: `brand`, `model`, `condition`, `production_year`.
- Только `kind=tyre`: `size`, `season`, `load_index`, `speed_index`,
  `rim_diameter` (дюймы), `aspect_ratio` (%), `tyre_width` (число и единица,
  например `295 mm` или `11 in`). Единицу ширины нельзя опускать.
- Только `kind=wheel`: `diameter`, `width` (дюймы), `wheel_offset`,
  `center_bore` (мм), `pcd`, `wheel_type`. Числа конечные; отрицательный ET разрешён.
- `price_min`, `price_max`: целые рубли, 0–1000000000 включительно.
- `tread_min`, `tread_max`: процент протектора 0–100 включительно.
- `in_stock=true`: запас больше нуля; пусто — любой запас.
- `sort`: `name`, `unit_price_rub`, `brand`; `direction`: `asc` или `desc`.
  По умолчанию UUID. При одинаковых значениях порядок определяется UUID;
  SQL NULL всегда в конце. Админка дополнительно сортирует по запасу,
  видимости и всем полям характеристик, как прежде.
- Только админка: `visibility=visible|hidden`, `stock_min`, `stock_max`
  (целые продаваемые единицы, 0–1000000000).

Нижняя граница не должна превышать верхнюю. Специфичные параметры требуют
явной соответствующей категории; без kind размерные фильтры отклоняются.
Неизвестные и повторяющиеся параметры,
невалидные значения дают 400 `validation_error`. Пустые значения не фильтруют.

## Значения фильтров

`GET /api/products/filters?kind=tyre` и защищённый
`GET /api/admin/products/filters?kind=tyre` возвращают
`{options: {brand: [...], size: [...], ...}}`.

Справочник строится из текущих товаров соответствующей категории и области
доступа. Пустые/неизвестные значения пропускаются, числа сортируются численно.
Публичный справочник не раскрывает характеристики скрытых товаров.
Другие фильтры не сужают справочник, чтобы пустой результат не мешал
пользователю выбрать другое значение. При ошибке справочника применение
фильтров блокируется, доступны повтор и сброс.

Размерные справочники заполняются только для выбранной категории. Ширина шины
возвращается с единицей (`315 mm`), в интерфейсе отображается «315 мм».
DTO details дополнен `tyre_width`, `tyre_width_unit`, `aspect_ratio`,
`rim_diameter`: это вычисляемые из size параметры, переданные клиентом значения
не записываются. Для дисков эти поля пусты; `diameter`/`width` относятся только
к дискам. `size` у диска сохраняет маркировку, но не используется в фильтрах.
Подробности хранения — [решение](../decisions/0006-typed-product-specifications.md).

## Интерфейсы

Витрина использует URL `/?kind=tyre&brand=...&page=2#catalog`:
24 товара на странице, page преобразуется в offset для API. Поиск применяется
кнопкой «Найти» или Enter, характеристики — кнопкой «Применить».
Изменение подбора/сортировки сбрасывает страницу; Back/Forward восстанавливают
состояние. Устаревшие запросы отменяются; загрузка не показывает прошлую выдачу.
Корзина остаётся независимой в localStorage, цены проверяются при оформлении.

Админка использует те же фильтры с дополнительными параметрами доступа/запаса;
фильтры хранятся в состоянии страницы, выбор колонок/сортировки — как прежде
по пользователю в localStorage. Смена категории сбрасывает специфичные для
типа поля. Пагинация админки — 50 строк, кнопка вперёд учитывает total.
