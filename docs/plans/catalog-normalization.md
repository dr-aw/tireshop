# Нормализация характеристик каталога

Задача 2026-10-29: сохранить общий товар и вынести характеристики в
`tyre_specs`/`wheel_specs`; затем разделить фильтры витрины и админки.

- [x] Аудит размеров и зависимостей; новая миграция с переносом данных,
  ограничениями типа и правами. Сохранить исходные значения, ID, остатки,
  версии, фотографии и заявки. Проверить перенос из предыдущей схемы.
- [x] Обновить чтение, атомарное редактирование и первоначальный импорт;
  отдельные единицы ширины шины и диаметры/ширины диска. Не угадывать профиль.
- [x] Разделить поля редактирования, характеристики и фильтры по категории;
  в общем каталоге только общие фильтры. Сбрасывать размерные фильтры при
  смене категории; сохранять URL/пагинацию и настройки таблицы.
- [x] Проверить API/ограничения/импорт/списание на временной БД, браузер,
  lint/build/test. Применить к локальной dev после проверки сохранности данных,
  обновить контракт/README/план.

Общий DTO чтения сохраняется для корзины и карточек, но источники характеристик
разные. Каталог остаётся одним сервисом, контракт заявок и списание не меняются.
Распознавать только однозначные метрические и дюймовые типоразмеры; исходный
размер сохранять всегда, непонятные единицы оставлять неизвестными.

## Результат

Миграция 00004 применена к tireshop_dev: 107 товаров, 89 шин, 18 дисков,
495 фотографий. Контрольные суммы общих полей/версий/запаса, фотографий,
исходных строк и контракта заявок совпали до/после; изменённых специализированных
значений относительно архива — 0. Все непустые текущие размеры шин распознаны.
Локальная копия четырёх таблиц каталога — .tmp/catalog-normalization/*-before.csv,
снята одной repeatable-read транзакцией. pg_dump не использован: клиент 16
несовместим с сервером 18; восстановление CSV описано в локальном README.

Test/race, lint, build, PostgreSQL integration и семь браузерных сценариев
прошли. Проверены перенос заполненной версии 3, FK типа, ограничения доступа,
откат смены категории, импорт/повтор и списание, пересчёт размера в редакторе,
фильтры/URL/корзина. Новый бинарник проверен с runtime-ролью на мигрированной dev
через временный порт; процесс проверки остановлен. Обычный dev требует
перезапуска mise run dev. Снимок мобильных фильтров просмотрен, Markdown/diff
проверены. Решение — docs/decisions/0006-typed-product-specifications.md.
