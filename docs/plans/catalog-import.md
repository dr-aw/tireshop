# Первоначальный перенос каталога и фотографий

Дата: 2026-10-28. Пользователь разрешил перенос всех данных из двух XLSX,
создание недостающих полей, обработку фотографий и сохранение рисунка-заглушки.
Оригиналы неизменны; приватные отчёты и производные не включаются в Git.

## Результат и границы

104 позиции (86 шин, 18 дисков), расширенная схема каталога, сохранённые
исходные строки и происхождение данных; нормализованные поля для API/UI.
Фотографии — отдельные записи с порядком, исходным путём, checksum и WebP.
Папка по стабильному ID товара; имена производных по checksum/настройкам,
чтобы обновление фото не ломало кеш. При отсутствии фото — текущий рисунок.

Первоначальная загрузка выполняется отдельным ограниченным процессом каталога,
вне HTTP API магазина/админки. Сначала staging/валидация, затем транзакционная
публикация через владельца каталога. Повтор того же источника не должен
перезаписывать ручные правки или восстанавливать уже списанный запас.
Регулярный импорт поставщиков и интерфейс очереди задач в этот шаг не входят.
Существующие заявки и синтетические позиции не удалять автоматически.

## Уточнения

- Подтверждено: «Количество» шин — текущий запас в штуках; «Остаток» —
  процент протектора. Устаревшая справка/сводка противоречат этим значениям.
- AU-2207: пользователь подтвердил 25 000 рублей за комплект из двух.
  Подтверждена продажа только комплектом, stock=1, units_per_sale=2.
- Проценты в столбцах признаны источником истины; названия исправляются,
  артикулы включаются в итоговый список для перепроверки. Вылет +118,5 подтверждён.
- Выявлены чужие артикулы в фото: SH-0076 → SH-0074, SU-1702 → SU-1703.
  Подтверждены исправления SU-1702/SU-1904 и добавление фото своего артикула
  из папки товара. Ссылки SH-0076 на SH-0074 не используются.
- Найдено 511 файлов, 647 ссылок из XLSX, 484 точных совпадения и 163
  отсутствующие ссылки. Это проверка имён, ещё не декодирования изображений.

## Результат

В dev перенесены 104 товара: 86 шин и 18 дисков. Все поля, исходные строки,
листы и формулы сверены с подготовленным набором. Запас шин 449 штук;
диски — 519 продаваемых единиц, 520 физических штук. Семь противоречий
«новая/б/у» сохранены скрытыми для отдельной проверки. Старые товары/заявки
не удалены. Повтор загрузки подтвердил no-op.

Обработаны все 511 изображений; 495 связаны с 80 товарами. Для 24 товаров
сохраняется рисунок-заглушка. Непривязанные WebP находятся в приватной `.tmp`.
Все производные проверены: 1280×1280, WebP, без EXIF/ICC/IPTC/XMP.
Общий размер привязанных WebP около 91 MiB, непривязанных — 2,9 MiB.
Локальный отчёт: `.tmp/catalog-import/RESULT.md`, полный аудит связей —
`.tmp/catalog-import/media.json.report.json`.

Test:integration проверил сохранение происхождения данных, конфликт SKU,
откат загрузки, продажу/списание комплекта и отсутствие восстановления остатка
при повторе импорта. Test:browser прошёл на синтетических данных: галерея,
оформление комплекта, снимок единицы, админка и прежние сценарии заказа.
Chromium установлен в текущий контейнер; использованы существующие библиотеки
из `.tmp/browser-libs`. Публикация сайта и новая сборка dev image не выполнялись.

Словарь и архитектура — [решение об импорте](../decisions/0005-initial-catalog-import.md).

Итоговые test (race), lint, build и проверка Markdown прошли. Статическая
сборка содержит подготовленные WebP. Изменения просмотрены, `git diff --check`
не обнаружил ошибок. Для работающего dev требуется перезапуск API.
